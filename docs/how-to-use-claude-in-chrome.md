# WSL上のClaude CodeからWindowsで起動中のChromeを操作する方法

WSL(Ubuntu)側で動いているClaude Codeから、Windows側のブラウザを直接操作(画面の閲覧・クリック・入力・スクリーンショット取得など)できるようにする手順です。知見がない人でも上から順に進めれば設定できるように、準備・起動・実際の使い方・トラブル対応の順にまとめています。

## 全体像

- Windows側のChrome(またはEdge)に「Claude in Chrome」という拡張機能を入れる。
- WSL側でClaude Codeを `--chrome` オプション付きで起動すると、この拡張機能経由でブラウザを操作できるようになる。
- Claude Codeは自分専用の「新規タブ」を開いて、その中で操作する。普段使っているタブ(既に開いている別のタブ)を勝手に覗いたり操作したりはしない。

## 1. 事前準備: Chrome拡張機能をインストールする

1. Windows側のChrome(またはEdge)で、拡張機能ストアから「Claude in Chrome」を検索してインストールする。
   - ChromeとEdgeの両方にインストールすること自体は可能。ただし同時に2つ入れていると、後述の「操作対象の選択」で紛らわしくなるため、**普段使う方をどちらか1つに決めておく**ことを推奨。
2. インストール後、ブラウザ右上の拡張機能アイコン(ジグソーパズルのマーク)をクリックし、「Claude in Chrome」を**ピン留め**して常時表示されるようにする。
3. ピン留めしたアイコンをクリックすると、ブラウザの右サイドバーにClaudeのチャット画面が開く。これで、今表示しているWebページの内容参照や操作が可能になる(このサイドバーからの単独利用と、Claude Code連携は別の使い方なので注意。次章で説明する連携方法を使う場合、サイドバーは必須ではない)。

## 2. Claude CodeをChrome連携ありで起動する

WSL側のターミナルで、いつも使っている作業ディレクトリに移動してから以下を実行する。

```bash
claude --chrome
```

`--chrome` を付けずに起動した通常のセッションでは、ブラウザ操作系のツールは使えない。ブラウザ操作をしたい作業をする場合は、必ずこのオプション付きで起動すること。

## 3. 実際にブラウザを操作してもらう

Claude Codeに「Chromeで◯◯を開いて」「今開いているページを見て」のように指示するだけでよい。内部的には次のような流れで動作する。

1. Claude Codeが拡張機能に接続する(初回や再接続時は、Windows側で拡張機能の許可・接続待ちが発生することがある)。
2. Claude Code専用の**新規タブ**が開かれる。既に開いている他のタブ(普段のブラウジング用タブ)とは別枠として扱われる。
   - そのため、「いま見ているこのタブを見て」と頼んでも、そのタブがClaude Code用のタブグループに属していない限り直接は見えない。見てほしいページがある場合は、**URLを伝える**か、「新しいタブで◯◯を開いて」と指示するのが確実。
3. 開いた新規タブの中で、ページの読み取り・クリック・フォーム入力・スクリーンショット取得などをClaude Codeが行う。

## 4. 複数のブラウザ・拡張機能が接続されている場合

同じアカウントでChrome拡張機能を複数のPC/ブラウザにインストールしている場合(例: 会社PCと個人PCの両方、あるいはChromeとEdgeの両方)、Claude Codeが「どのブラウザを操作対象にするか」を確認してくることがある。

その場合、次のいずれかの方法で選択する。

- 候補一覧(表示名+deviceID)から使いたいブラウザを直接選ぶ。
- どれか分からない・一覧の表示名だけでは判別しづらい場合は、「確認画面で選ぶ」を選択する。これを選ぶと、接続されている**すべての**拡張機能に確認プロンプトが送られるので、実際に使いたいPC・ブラウザ側で表示される確認画面の「Connect」ボタンを押す。押した方が操作対象として選択される。

一度選択したブラウザは、そのセッション中は記憶される。別のセッションで再度確認された場合も、同じ手順で選び直せばよい。

## 5. トラブルシューティング

- **「拡張機能が古いモデルしか選べない」**: Chrome拡張機能はChromeの自動更新の仕組みに乗っており、通常は数時間おきにバックグラウンドで最新版に更新される。すぐに反映したい場合は、`chrome://extensions` を開き、右上の「デベロッパーモード」をON→左上の「更新」ボタンをクリックして手動で更新チェックできる。それでも変わらない場合は拡張機能を一度無効化→有効化するか、ブラウザを再起動する。
- **タブが見つからない・操作対象のタブIDが無効というエラーが出る**: ブラウザ側でそのタブを閉じてしまった、または別セッションのタブIDを使い回そうとした可能性がある。Claude Codeに「タブの状況を確認して」と伝えれば、利用可能なタブ一覧を取り直して再試行できる。
- **接続待ちのまま反応がない**: Windows側で拡張機能の確認ダイアログ(「Connect」ボタンなど)が表示されていないか確認する。ダイアログを見落として放置すると接続待ちのままになる。
